# BHUTE - Black Hurricane Undertale Engine

## 项目介绍

BHUTE是一个专为制作Undertale同人游戏而设计的完整游戏开发模板，基于GameMaker引擎开发。该模板提供了一套完整的Undertale风格游戏系统，包括战斗系统、UI界面、对话系统等核心功能，旨在帮助开发者更快速、更便捷地创建高质量的Undertale同人作品。

### 核心功能
- **完整的战斗系统**：包括回合制战斗、子弹弹幕、灵魂移动等Undertale经典战斗元素
- **丰富的UI界面**：预建的主菜单、设置界面、战斗界面等，支持多语言切换
- **灵活的对话系统**：支持文本动画、多语言对话等功能
- **视觉特效系统**：包括模糊、发光、震动等视觉效果
- **音效管理系统**：预配置的音效系统，支持背景音乐和音效的管理
- **多语言支持**：内置中英文支持，可扩展其他语言

## 使用需求
- Windows 10及以上操作系统
- GameMaker Studio 2（推荐最新版本）
- 可运行Steam的环境（用于某些功能的正常运行）
- 至少4GB RAM，推荐8GB以上
- 至少500MB可用磁盘空间

## 安装与使用

### 安装步骤
1. **获取GameMaker**：从[GameMaker官网](https://gamemaker.io/en)下载并安装GameMaker Studio 2
2. **下载模板**：从项目的[Release页面](https://github.com/BlackHurricaneDev/BHUTE/releases)获取最新版本的模板文件（BHUTE.yyz）
3. **导入模板**：打开GameMaker Studio 2，选择"导入"选项，浏览并选择下载的BHUTE.yyz文件
4. **等待导入**：导入过程可能需要几分钟时间，取决于您的计算机性能
5. **开始使用**：导入完成后，您可以开始基于模板创建自己的游戏

### 快速开始
1. **熟悉项目结构**：浏览项目的目录结构，了解各个文件和文件夹的作用
2. **修改游戏设置**：在GameMaker的项目设置中，修改游戏的基本信息和参数
3. **替换资源**：将模板中的占位资源替换为您自己的游戏资源
4. **创建场景**：使用模板提供的系统创建游戏场景和剧情
5. **测试运行**：定期测试游戏，确保所有功能正常运行

## 项目结构

```
BHUTE/
├── animcurves/       # 动画曲线定义
├── fonts/            # 字体资源
├── objects/          # 游戏对象
├── rooms/            # 游戏场景
├── scripts/          # 脚本文件
└── sounds/           # 音效资源
```

### 关键文件说明
- **objects/obj_init/**：游戏初始化对象，定义核心常量和系统
- **objects/obj_main_menu_draw/**：主菜单绘制对象，管理主菜单逻辑
- **objects/obj_battle/**：战斗系统核心对象，处理战斗逻辑
- **scripts/Input_Check/**：输入检查系统，处理玩家输入
- **scripts/Battle_**：战斗相关脚本，实现战斗系统功能

## 自定义指南

### 资源替换
1. **图像资源**：替换sprites文件夹中的图像资源
2. **音效资源**：替换sounds文件夹中的音效文件
3. **字体资源**：替换fonts文件夹中的字体文件

### 菜单定制
1. 修改`objects/obj_main_menu_draw/Create_0.gml`中的菜单结构
2. 调整`objects/obj_main_menu_draw/Draw_0.gml`中的菜单绘制逻辑

### 战斗系统配置
1. 修改`objects/obj_battle/`中的战斗参数
2. 调整`scripts/Battle_`相关脚本以适应您的游戏需求

### 多语言支持
1. 在语言文件中添加新语言的翻译
2. 修改`scripts/GetTranslation/`相关脚本以支持新语言
